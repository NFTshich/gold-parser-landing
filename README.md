# Gold Parser — оценка лотов с драгметаллами

**Программный инструмент для поиска и оценки лотов (микросхемы, транзисторы,
конденсаторы, платы, радиостанции и т.п.), в которых содержатся драгоценные
металлы (золото, палладий, платина).**

> Продукт находится в продаже. Исходный код распространяется по договору,
> здесь — только описание возможностей и контакты.

---

## Что умеет

- **Автоматическая оценка лота**: подставляет тип детали по названию и описанию
  из справочника, умножает содержание металла на количество и считает
  **стоимость металла, маржу и кратность** («металл в N раз дороже цены лота»).
- **Мониторинг объявлений**: постоянно сканирует источники и подсвечивает только
  **новые** выгодные лоты с ссылкой, без дублей. Настраиваемый порог кратности и
  авто-открытие найденного в браузере.
- **Актуальные цены драгметаллов** с официального курса ЦБ РФ за грамм
  (золото, серебро, платина, палладий) с кэшем и ручным вводом.
- **Прайсы скупщиков**: закупочные цены перекупщиков радиодеталей для калибровки
  справедливой цены «выхода».
- **Поиск по площадкам и барахолкам**, чтение Telegram-каналов и групп VK
  (публичных стен, без токена), поиск по всему VK при наличии токена.
- **Импорт/экспорт**: ручной ввод, импорт из CSV, отчёты в CSV (читаются в Excel).
- **Самопроверка**: встроенные тесты без выхода в интернет.

## Для чего

Поиск лотов, где **стоимость драгметаллов минимум в 3 раза выше цены лота** —
база для перепродажи. Золото, палладий и платина учитываются в марже; серебро —
только в ценах (по настройке). Пороги кратности и маржи настраиваются.

## Технологии

- Python 3.10+, только стандартная библиотека (без тяжёлых зависимостей)
- Кроссплатформенно (Windows/Linux), запуск через `run.bat` или командную строку
- Работает с официальными ценами ЦБ РФ, открытыми форумами и соцсетями

## Формат продажи

- Готовый инструмент под ключ с инструкцией по установке и настройке
- Индивидуальная калибровка справочника типов деталей под ваши нужды
- Обучение и консультации по запуску
